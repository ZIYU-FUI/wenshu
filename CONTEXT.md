# CONTEXT · Wenshu (文枢)

> Domain glossary for wenshu. Every agent reads this before working on the project. Update when a new domain word enters the codebase.
> English-only rule applies (see `AGENTS.md` top section). Sole address for the user = "老板".

## Identity

- **wenshu / 文枢** = Apple-stack-exclusive long-form fictional-novel AI authoring platform.
- 老板 拍板 2026-08-06: self-built lightweight AI kernel, no external AI platform calls.
- v1 LLM provider = **minimax cn** (Anthropic-compatible protocol).
- Apple-stack exclusive (macOS / iPad / iPhone). 老板 8/18 拍 = macOS-only single target.
- Project root = `/Volumes/ANAN/Engineering/wenshu/`.

## Architecture

- **Stack** = Swift / SwiftUI + CoreData + single-process coroutine + self-built lightweight AI kernel.
- **Storage** = `.ws` single file = CoreData + attachments, locally self-managed, path `~/Documents/wenshu/<id>/`.
- **Build** = SwiftPM, `.macOS(.v27)` single platform, `Package.swift` as single entry.
- **LSP / LLM** = no external AI platform calls in any code file.
- **NOT used** = UIKit, Tauri, Rust, SQLite, Vue 3, sparse-clone, novel-platform / novel-craft / Hermes-Slate-Desk legacy V0.5.x protocol.
- **NOT used** = iOS / iPadOS / Catalyst adapter (dead code per 老板 8/18 拍).

## Project conventions (hard constraints)

- Forbidden vocabulary (修真 / 渡劫 / 筑基 / 返虚 / 结丹 / 金丹 / 元婴 / 飞升 / 天劫 / 雷劫 / 心魔 / 魔障) all banned. Use 修 / 改 / fix / 替换 / 调整.
- Sole address for 老板 = 老板. No earlier honorific forms (老板 already purified in v0.07).
- No decorative emoji. No open-ended prologues / endings. No oversized headings.
- First line = fact. Last line = fact.
- Forbidden neutral words (可 / 应当 / 或许 / 可能 / 应该 / 建议 / 考虑 / 试图 / 尽量 / 大概 / 也许 / 或 / 任意 / 大概率 / 通常 / 一般来说) all banned. Use certain words (是 / 否 / 行 / 不行 / 可以 / 不可以 / 不变 / 变).
- Apple-stack exclusive → any generic placeholder / iOS / iPadOS / Catalyst adapter = dead code = delete.
