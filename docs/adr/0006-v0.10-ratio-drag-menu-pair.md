## Decision

The v0.10 stage's 9 commits accumulated 4 major decisions:

1. **Ratio conversion** (v0.10.0): 18 PT absolute values → 18 ratio operators (0~1), LayoutShellView top-level GeometryReader × ratio = adapts 1:1 to any window size
2. **Drag interaction** (v0.10.1 + v0.10.3): 5 vertical drag splitters (D_v1~D_v5, 老板 8/18 拍 50/50 horizontal D_h inert) onDrag → LayoutShellViewModel 5-offset chain → @Observable rerenders zone widths
3. **View menu** (v0.10.2): CommandMenu("视图") + "恢复默认布局" ⌘⇧R + NotificationCenter.default bridge to vm.reset()
4. **Ratio-pair formula** (v0.10.4~v0.10.6): 8-zone 200/middle/400 ratio-pair (top 4 + bottom 3) + H/W dual pair conservation at 1.0 (39+472+472+1=984 + 1 PT splitter visual line distributed to left/right)

Side decision: v0.10.7 added RoundedRectangle bordered rounded input box → v0.10.8 removed it (老板 re-read the original Sketch and it wasn't drawn)

## Consequences

- 8-zone ratio-pair conservation at 1.0: 200+558+762+400 = 1920 (top) / 200+1320+400 = 1920 (bottom)
- H ratio-pair: 39+472+472+1 = 984
- 5 drag splitters draggable, VM persists 5-offset accumulation (default ±0.10 range)
- Out-of-bounds rejected per-band (top band 4 zones max 60%, bottom band 2 zones max 95%)
- View menu 8 top-level menus (Apple/Wenshu/File/Edit/View/Window/Help) + View contains "恢复默认布局"
- Input box added in v0.10.7, removed in v0.10.8; current code does not render a chat input box

- v0.10.1 alt: SwiftUI DragGesture — rejected, flickers across render
- v0.10.2 alt: toolbar button + shortcut key — rejected, 老板 拍 "menu bar"
- v0.10.3 alt: 2 zones (chatManagement + dynamicZone) — rejected, 老板 拍 "lower half 3 zones"
- v0.10.5 alt: drag splitter deducts ratio (middle 1+2 = 1317) — rejected, 老板 拍 "ratio-pair" = splitter line distributed to left/right
- v0.10.6 alt: horizontal drag splitter ratio = 0 (not counted) — rejected, ratio-pair conservation at 1.0 requires horizontalSplitterRatio = 1/984
- v0.10.7 alt: keep solid blue filled input box — rejected, 老板 removed after re-reading original
