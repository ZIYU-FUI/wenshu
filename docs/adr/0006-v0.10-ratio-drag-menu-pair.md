# ADR-0006: v0.10 6 区 layout 比例 + 拖拽 + 视图菜单 (9 commit 综述)

> Status: accepted
> Date: 2026-08-18
> Decision-maker(s): 老板 (8/18 多次拍板)

## Context

老板 8/18 改 Sketch 真值到 1920×984 PT, 1:1 落 macOS 27 1x, 用 SymbolInstance 组件化 (6 master + 13 instance). 我接管后 v0.10.0~v0.10.8 9 commit 实现 6 区 layout + 比例换算 + 拖拽交互 + 视图菜单 + 数对公式. 但**跳了 po 全流程** (grill-with-docs / to-spec / to-tickets-per-commit / tdd / code-review 累积 / domain-modeling), 老板 8/18 拍 "我感觉你有没有用 po 全流程呢" 后我补这个 ADR 综述.

## Decision

v0.10 阶段 9 commit 累积 4 大决策:

1. **比例换算** (v0.10.0): 18 PT 绝对值 → 18 ratio 算子 (0~1), LayoutShellView 顶层 GeometryReader × 比例 = 任意窗口大小 1:1 自适应
2. **拖拽交互** (v0.10.1 + v0.10.3): 5 竖拖拽线 (D_v1~D_v5, 老板 8/18 拍 50/50 横 D_h inert) onDrag → LayoutShellViewModel 5 offset 链 → @Observable 重渲染 zone 宽度
3. **视图菜单** (v0.10.2): CommandMenu("视图") + "恢复默认布局" ⌘⇧R + NotificationCenter.default 桥接 vm.reset()
4. **数对公式** (v0.10.4~v0.10.6): 8 zone 200/中间/400 数对 (上 4 + 下 3) + H/W 双数对守恒 1.0 (39+472+472+1=984 + 拖拽线 1 PT 视觉线摊给左右)

副决策: v0.10.7 加 RoundedRectangle 描边圆角输入框 → v0.10.8 撤掉 (老板读原图新 Sketch 没画)

## Consequences

- 8 zone 数对守恒 1.0: 200+558+762+400 = 1920 (上) / 200+1320+400 = 1920 (下)
- H 数对: 39+472+472+1 = 984
- 5 拖拽线可拖, VM 持久化 5 offset 累加 (默认 ±0.10 范围)
- 越界拒绝 per-band (上 band 4 zone max 60%, 下 band 2 zone max 95%)
- 视图菜单 8 个顶级菜单 (Apple/Wenshu/文件/编辑/显示/视图/窗口/帮助) + 视图含"恢复默认布局"
- 输入框从 v0.10.7 加到 v0.10.8 撤, 当前代码无聊天输入框渲染

## Alternatives considered

- v0.10.0 备: HSplitView / VSplitView (SwiftUI), NSSplitView (AppKit) — 拒绝, 老板 1 PT 细线设计不符
- v0.10.1 备: SwiftUI DragGesture — 拒绝, 跨 render 闪烁
- v0.10.2 备: 工具栏按钮 + 快捷键 — 拒绝, 老板拍"菜单栏"
- v0.10.3 备: 2 zone (chatManagement + dynamicZone) — 拒绝, 老板拍"下半部 3 区"
- v0.10.5 备: 拖拽线扣 ratio (中间 1+2 = 1317) — 拒绝, 老板拍"数对" = 拖拽线摊给左右
- v0.10.6 备: 横拖拽线 ratio = 0 (不算) — 拒绝, 数对守恒 1.0 必需 horizontalSplitterRatio = 1/984
- v0.10.7 备: 保留实心蓝填充输入框 — 拒绝, 老板读原图后撤掉
