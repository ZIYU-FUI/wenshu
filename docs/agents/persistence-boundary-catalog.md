# Persistence Boundary Catalog (v3.1 governance A1a probe)

Tells which Repository can move to `WenshuData` local SwiftPM package
AS-IS (= works after move), and which require an app-domain decoupling
fix FIRST (= blocked until A1d).

## A1a probe result (= 2026-10-15)

Tried moving `Sources/WenshuApp/Persistence/` (38 files, 22 @Model +
Container + ModelsSchema + TypedID + LibraryMigrationState + 8
Repository + 1 Container) to local SwiftPM package `WenshuData`. Build
failed:

```
WSMemoryRepository.swift:41:16: error: cannot find 'Memory' in scope
WSMemoryRepository.swift:55:13: error: cannot find 'Memory' in scope
WSMemoryRepository.swift:73:13: error: cannot find 'Memory' in scope
WSMemoryRepository.swift:117:13: error: cannot find 'Memory' in scope
WSChatRepository.swift:116: error: cannot find 'StoredChatMessage' in scope
WSChatRepository.swift:196: error: cannot find 'BookID' in scope
```

Root cause = 2 Repository files hold **app-side domain types** (= `Memory`,
`StoredChatMessage`, `BookID`) inside the data layer. Per Apple
Backyard Birds canonical, the data layer (= `WenshuData` package) must
NOT reference app-side domain types; the conversion belongs in caller
code (= app target).
