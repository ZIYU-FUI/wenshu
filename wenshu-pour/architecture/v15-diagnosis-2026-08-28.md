1. **`apps/desktop/package.json:212`** — LSEnvironment 注入 literal `"$HOME/.wenshu-hermes"`:

   - macOS LSEnvironment 不展开 `$HOME` 字面字符串,直接传给子进程

2. **macOS .app 启动 → Electron main 进程**:
   - `process.env.HERMES_HOME = "$HOME/.wenshu-hermes"` (字面,带前导 `$HOME`)

3. **`apps/desktop/electron/main.ts:411`** — 兜底 fallback 失败:
   ```ts
   if (!process.env.HERMES_HOME) {process.env.HERMES_HOME = path.join(os.homedir(), '.wenshu-hermes')}
   ```
   - ❌ 触发条件:HERMES_HOME 未设时兜底
   - ❌ 实际:HERMES_HOME 已设 (字面 `$HOME/.wenshu-hermes`,非空) → fallback 不触发
   - 结果:`process.env.HERMES_HOME` 仍是字面 `$HOME/.wenshu-hermes`

4. **`main.ts:467` `resolveHermesHome()`**:
   ```ts
   function resolveHermesHome() {
     if (process.env.HERMES_HOME) {
       return normalizeHermesHomeRoot(process.env.HERMES_HOME)
     }
     ...
   }
   ```
   - `normalizeHermesHomeRoot("$HOME/.wenshu-hermes")` → `path.resolve("$HOME/.wenshu-hermes")` → Node.js 给字面相对路径前置 `/` → `/$HOME/.wenshu-hermes` (字面,带前导 `/`)

5. **`main.ts:1646` spawn hermes serve env**:
   ```ts

   ```
   - `HERMES_HOME` 常量 = `/$HOME/.wenshu-hermes` (字面)
   - 传给 Python hermes-cli 子进程 → `os.environ["HERMES_HOME"] = "/$HOME/.wenshu-hermes"`

6. **Python `hermes_constants.py:64`**:
   ```python
   val = os.environ.get("HERMES_HOME", "").strip()
   ```

   - 读到字面 `/$HOME/.wenshu-hermes` → `Path("/$HOME/.wenshu-hermes")`

## 3. v15 BUG 拍板真值小结

**v15 BUG 根因** = macOS LSEnvironment 注入 literal `$HOME/.wenshu-hermes` (不展开) → Electron main 进程继承 → main.ts:411 兜底失败 (literal 非空) → main.ts:467 path.resolve 给字面相对路径前置 `/` → spawn Python hermes-cli 时 env 传字面 `/$HOME/.wenshu-hermes` → Python hermes_constants.get_hermes_home() 拿到字面 Path → hermes_logging.setup_logging() mkdir 字面 `/$HOME/.wenshu-hermes/logs` → ENOENT fail → 桌面 app 弹 "文枢 couldn't start"。

**修法 (5 候选组合)**:
1. **主修 (Node.js 端)**: main.ts:411 替换为字面 `$HOME` / `~` 检测 + os.homedir() 兜底 (候选 1+4)
2. **主修 (Node.js 端)**: bootstrap-runner.ts 加 `_resolveHermesHomeSafe()` helper,替换 2 处 spawn env (候选 1+4)
3. **防御 (Python 端)**: managed_uv.py + auth.py top-of-file sanitize os.environ["HERMES_HOME"] (候选 2+5)

**修后验证**: Node.js 端修复后,Python 端永远不会收到字面 `$HOME` env var → setup_logging mkdir 用绝对路径 `/Users/anbaiqiang/.wenshu-hermes/logs` → 成功。
