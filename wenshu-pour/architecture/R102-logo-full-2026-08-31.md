### 步骤 1: 调研 - electron-builder + Tauri icon 格式要求
- electron-builder `mac.icon` / `build.icon`: 读无扩展名文件 (例如 `assets/icon`),
  自动选 .icns (mac), .ico (win), .png (linux). 见 packages/app-builder-lib/scheme.json
  MacConfiguration.icon 定义: 可为 string 或 array of strings.
- Tauri v2 `bundle.icon`: 数组格式, 平台各自解析 — .icns 给 mac, .ico 给 win, .png 给 linux.
  见 tauri.conf.json 当前 schema:
    ["icons/32x32.png","icons/128x128.png","icons/128x128@2x.png",
     "icons/icon.icns","icons/icon.ico"]
- 装机 user 浅色 LOGO 资源大小已覆盖所有要求 (1024x1024 + icns 多块 + ico 多块 + 32/128/256).
