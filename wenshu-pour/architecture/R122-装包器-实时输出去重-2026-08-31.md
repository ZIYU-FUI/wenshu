# WO-001BI-R122: 修 装包器前端实时输出重复 2 行 (删 main.tsx 重复 initialize 调用)

[装机 user 8/31 反馈]
- "看到实际输出没, 同样的内容会输出两行"

[真根因]
- 装包器 React 入口 main.tsx 跟 app.tsx 都调 initialize()
- 两次初始化会并发拉取状态、注册/重置 bootstrap 事件流
- 同一 log 行前端 dup 2 次

[修法]
- 删 apps/bootstrap-installer/src/main.tsx 第 49 行 void initialize() 调用及其 import
- 保留 App shell (app.tsx useEffect) 单一 init path
- React StrictMode 不会 创双 startup path

[验证]
- pnpm exec tsc --noEmit --project apps/bootstrap-installer/tsconfig.json ✅
- pnpm --dir apps/bootstrap-installer build ✅
- cargo check --manifest-path apps/bootstrap-installer/src-tauri/Cargo.toml ✅

- 跑新 DMG 装包器 (PM-direct 重 build 拷 ~/Downloads)
- 验实时输出 不重复
