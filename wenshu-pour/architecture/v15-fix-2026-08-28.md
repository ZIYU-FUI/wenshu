## 2. 主修 (Node.js 端)

### 2.1 `apps/desktop/electron/main.ts:411` — 兜底逻辑替换

**改前**:
```ts
if (!process.env.HERMES_HOME) {process.env.HERMES_HOME = path.join(os.homedir(), '.wenshu-hermes')}
```

**改后**:
```ts
// HERMES_HOME 兜底 — 处理 macOS LSEnvironment 注入 literal "$HOME/.wenshu-hermes" 的情况
// (apps/desktop/package.json mac.extendInfo.LSEnvironment 设置了字面 $HOME 占位符,
//  macOS LSEnvironment **不展开** $HOME → Electron main 进程继承到字面 HERMES_HOME="$HOME/.wenshu-hermes";
//  下游 main.ts:467 resolveHermesHome() 经 path.resolve() 给字面相对路径前置 "/" →
//  HERMES_HOME="/$HOME/.wenshu-hermes" → spawn Python hermes-cli 时 env 传过去 →
//  hermes_constants.get_hermes_home() 拿到 Path("/$HOME/.wenshu-hermes") →
//  hermes_logging.setup_logging() 试图 mkdir "/$HOME/.wenshu-hermes/logs" → ENOENT fail,
//  桌面 app 弹 "文枢 couldn't start" 错误 — WO-001BE v15 BUG 根因).
// 触发条件: 空 / 包含 $HOME 或 ${HOME} 字面 / 以 ~ 开头 → 用 os.homedir() 解析成绝对路径.
{
  const _rawHome = process.env.HERMES_HOME
  const _hasDollarHomePlaceholder = !!_rawHome && (/\$\{?HOME\}?/.test(_rawHome) || _rawHome.trim().startsWith('~'))
  if (!_rawHome || _hasDollarHomePlaceholder) {
    process.env.HERMES_HOME = path.join(os.homedir(), '.wenshu-hermes')
  }
}
```

**修法要点**:
- 单行 `if (!process.env.HERMES_HOME)` 替换为 block (检测字面 `$HOME` / `~`)
- 正则 `/\$\{?HOME\}?/` 匹配 `$HOME` 和 `${HOME}` 两种字面形式
- `_rawHome.trim().startsWith('~')` 兼容 `~` 开头
- 检测到字面 → 强制 `os.homedir()` 解析为绝对路径
- 检测到空 / 未设 → 同上兜底

**作用链**:
- `process.env.HERMES_HOME` 在 line 411 处已 sanitized
- `main.ts:467 resolveHermesHome()` 内部读 `process.env.HERMES_HOME` → 拿到绝对路径
- `const HERMES_HOME = resolveHermesHome()` 后续所有 spawn 都用这个常量 → 全部正确
- 拍板真值: Node.js 端 spawn Python hermes-cli 时,`HERMES_HOME` 永远是绝对路径 → Python 端 `os.environ["HERMES_HOME"]` 永远正确 → setup_logging mkdir 用绝对路径 → 成功

### 2.2 `apps/desktop/electron/bootstrap-runner.ts` — 加 helper + 替换 2 处 spawn env

**改前** (line 473 + line 569):
```ts
HERMES_HOME: hermesHome || process.env.HERMES_HOME || ''
```

**改后** (line 490 + line 586):
```ts
HERMES_HOME: _resolveHermesHomeSafe(hermesHome)
```

**helper 加在 line 46**:
```ts
import os from 'node:os'

// _resolveHermesHomeSafe — expand literal "$HOME/.wenshu-hermes" (or "~") placeholders
// into a real absolute path. macOS LSEnvironment injects LSEnvironment vars as literal
// strings (no shell expansion), so the desktop process can inherit HERMES_HOME="$HOME/..."
// from apps/desktop/package.json mac.extendInfo.LSEnvironment. Passing that literal down
// to install.ps1 / install.sh / Python hermes-cli causes ENOENT mkdir "$HOME/.wenshu-hermes/logs".
// main.ts:411 already filters process.env.HERMES_HOME globally; this is defense in depth
// for cases where bootstrap-runner.ts is called with an explicit hermesHome arg that
// itself came from a similarly-polluted source (e.g. a stale shell init file).
function _resolveHermesHomeSafe(hermesHome: string | undefined | null): string {
  const raw = hermesHome ?? process.env.HERMES_HOME
  if (!raw || (/\$\{?HOME\}?/.test(raw) || raw.trim().startsWith('~'))) {
    return path.join(os.homedir(), '.wenshu-hermes')
  }
  return raw
}
```

**修法要点**:
- 提取共享 helper `_resolveHermesHomeSafe()` — 检测逻辑与 main.ts:411 一致
- `hermesHome ?? process.env.HERMES_HOME` — 优先用 caller 传的 hermesHome arg
- 检测到字面 `$HOME` / `~` / 空 → 用 `os.homedir()` 兜底
- 替换 `spawnPowerShell` (line 473) 和 `spawnBash` (line 569) 两处 spawn env

**作用链**:
- bootstrap-runner.ts spawn `install.ps1` / `install.sh` 时,`HERMES_HOME` 永远是绝对路径
- 即使 main.ts:411 兜底被绕过 (例如 desktop 进程从其他 spawn 路径启动),bootstrap-runner 也自带兜底

## 3. 防御 (Python 端,白名单内)

### 3.1 `~/.wenshu-hermes/hermes-agent/hermes_cli/managed_uv.py` — top-of-file sanitize

**加在 line 22 (before `from hermes_constants import get_hermes_home`)**:
```python
import re as _re

# Defense in depth — WO-001BE v15 BUG fix
# 桌面 app spawn Python 时 main.ts:411 已经过滤 literal $HOME (来自 macOS LSEnvironment),
# 但用户直接跑 hermes 命令 / 其他 spawn 路径也可能拿到 literal HERMES_HOME.
# 在 import get_hermes_home 之前先 sanitize os.environ["HERMES_HOME"]:
#   1) 空 → 不动 (get_hermes_home 自己有 Path.home() fallback)
#   2) 包含 $HOME 或 ${HOME} 字面 → os.path.expandvars
#   3) 以 ~ 开头 → os.path.expanduser
# 触发后再覆盖 os.environ,确保下游 get_hermes_home() 拿到绝对路径.
_hermes_home_env = os.environ.get("HERMES_HOME", "")
if _hermes_home_env and (
    _re.search(r"\$\{?HOME\}?", _hermes_home_env)
    or _hermes_home_env.lstrip().startswith("~")
):
    _expanded = os.path.expandvars(os.path.expanduser(_hermes_home_env))
    if _expanded and _expanded != _hermes_home_env:
        os.environ["HERMES_HOME"] = _expanded

from hermes_constants import get_hermes_home
```

**作用**: managed_uv.py import 时 (uv 命令需要),若 `os.environ["HERMES_HOME"]` 含字面 `$HOME` / `~`,自动 sanitize 为绝对路径。

**限制**: managed_uv.py 是 lazy import (main.py:6582/9870/10394 在函数内 import),setup_logging 调用时已晚,但其他 managed_uv 入口 (用户直接跑 `hermes uv install` 等)受益。
