# B-07 015.019 — book count right status (boss 2026-09-04 OOB '往后推进')

## Goal

Make the sidebar bottom-status "书: N" reflect the actual library
book count via a reactive `BookStore.books` property, instead of
an inline filesystem scan at render time.

## Background

Ticket 015.019 originally landed in v0.24 (= commits `9950fc47e`
+ `42bb97f7f`) by adding `WenshuLibrary.bookCount` /
`recomputeBookCount()` (= computed by iterating `store.loadBooks`
per shelf; cached on the @Observable mirror).

v0.30 boss 8/31 OOB fix (commit `29666ede9`) extended the wiring
further: `TabContentDispatcher` reads `bookStore.shelves.count`
for shelves, but for books it still does an inline
`FileManager.default.contentsOfDirectory` walk inside the view
body. That scan runs on every render and is not reactive (= if a
book is added/removed through any path that does not trigger a
re-render of the sidebar chrome, the count drifts until the next
re-render).

## Acceptance

- `BookStore` exposes a reactive `books: [Book]` property loaded
  via the existing `sidebarLoadAllBooks()` helper, refreshed by
  `reloadAllBooks()` (public).
- `BookStore.sidebarSaveBook(_:)` and a new
  `BookStore.sidebarDeleteBook(id:)` keep `books` in sync (= no
  stale counts after add/remove).
- `TabContentDispatcher.swift` line 96-111 reads
  `bookStore.books.count` instead of running the inline
  filesystem scan.
- The bottom status text continues to render "书: N" with the
  correct N (= zero books → "书: 0"; one book → "书: 1"; etc.).
- 3 round-trip tests pass:
  1. `testBookCount_zeroLibrary` — empty library → `books.count == 0`.
  2. `testBookCount_withOneBook` — one saved book → `books.count == 1`.
  3. `testBookCount_addAndRemoveBook` — add then delete → count
     returns to the pre-add value.
- swift build + swift test exit 0.
- Working tree clean after push.

## Scope guard (= no side effects)

- No change to `WenshuLibrary.bookCount` (kept for back-compat).
- No change to `projectSidebarChrome(shelfCount:bookCount:)`
  signature.
- No change to existing `BookStore` public methods.
- Only one new method (`reloadAllBooks()`) and one updated method
  (`sidebarSaveBook(_:)` appends; `sidebarDeleteBook(id:)` removes)
  on BookStore.
- No change to `App.swift` / `LibraryLifecycleHook` (existing
  `BookStore(stores:)` init signature is preserved).
