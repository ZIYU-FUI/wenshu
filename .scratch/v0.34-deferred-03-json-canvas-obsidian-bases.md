# v0.34 Deferred Spec #3 — JSON Canvas + Obsidian Bases Rendering

## Origin

Deferred from `.scratch/v0.34-editor-preview-and-expand/spec.md` "Out of Scope" line 9:
> JSON Canvas / Obsidian Bases rendering (= boss didn't mention = v0.35+ tickets)

Two distinct sub-features bundled under one ticket per boss OOB:

1. **JSON Canvas 1.0** (= `jsoncanvas.org` spec, Obsidian-native canvas file format) — infinite-canvas node-edge graph for brainstorming / outlining
2. **Obsidian Bases** (= `.base` YAML file format, Obsidian 1.9+ feature) — database / table view of book metadata

## Goal

Open and render two Obsidian-adjacent file formats inside the editor zone:
- `.canvas` files → infinite-canvas render (= nodes draggable, edges connectable)
- `.base` files → table / card / grid view of structured book metadata

Both formats coexist with existing MD chapter rendering. Edit mode for both = source MD / YAML / JSON; preview mode = rich render.

## User-Facing UX

### JSON Canvas (.canvas)
- **Preview mode**: infinite pan / zoom canvas (= 2D plane with drag / pinch). Nodes render as rounded rectangles with title + body text (= monospace for code nodes). Edges render as straight or labeled arrows.
- **Node types**: text (= default), file (= links to .md chapter), link (= URL), group (= background tint + label).
- **Edit mode**: switch to JSON source (= `TextEditor` rendering raw `.canvas` JSON). Mode toggle = existing eye/pencil button.
- **Save**: `Cmd+S` writes back JSON (= preserves node positions, edge labels, group tints).
- **Tab integration**: opens as new tab in `PaneTabBar.foreshadowing` slot (= repurposed; new file-type tab).

### Obsidian Bases (.base)
- **Preview mode**: table view (= rows = book entries, columns = user-defined properties from `.base` YAML `properties:` block). Each row click → opens corresponding MD chapter (= existing `WenshuEditorServicesFactory.openChapter`).
- **View modes**: 3 = table (= default), card (= per-entry card stack), grid (= image grid if entry has cover). Mode switcher = top-right `.picker` (= Apple HIG standard).
- **Filter bar**: YAML-driven (= `filters:` block in .base file). Filters apply via `Predicate` evaluation (= pure-Swift, no JS).
- **Edit mode**: switch to YAML source (= `TextEditor` rendering raw `.base` YAML).
- **Save**: `Cmd+S` writes back YAML (= preserves column order, view mode, filters).

## Apple HIG Justification

- **Rule 14 (Charts / graphs)**: infinite-canvas pan / zoom uses Apple HIG standard gestures (= `MagnificationGesture` + `DragGesture`). No custom gesture recognizers.
- **Rule 15 (Canvas / drawing)**: node + edge rendering uses SwiftUI `Canvas` (= GPU-accelerated). Node text uses `Text(_:)` inside `Canvas` `GraphicsContext.draw(_, at:)`.
- **Rule 10 (Tab / navigation)**: `.canvas` and `.base` files open as new file-type tabs in existing `PaneTabBar` (= no new top-level nav).
- **Rule 12 (Color & contrast)**: group tints (= JSON Canvas `color` field) map to Apple HIG system colors (= `Color.accentColor`, `.secondary`, `.tertiary`). No arbitrary hex (= respects Apple HIG accessibility).
- **Rule 11 (State persistence)**: per-book view mode (table / card / grid) persists via `@AppStorage("bases.viewMode")`. Standard storage.

## Open Questions (for Boss)

1. **YAML dependency**: Obsidian Bases = YAML format. `Yams` (= 1.1k★, MIT, jpsim/Yams) is the canonical Swift YAML parser but NOT yet pinned in wenshu. Options: (a) add `Yams` (= passes §11.1 acceptance: 1.1k★, MIT, last commit < 12 months, macOS-supported), (b) hand-roll minimal YAML parser (= only needs `key: value` + nested list for `.base` files = ~80 LOC).
2. **JSON Canvas 1.0 spec version pin**: current spec = jsoncanvas.org 1.0 (2024-09 release). Future 1.x updates? Proposal = pin to 1.0, bump on minor spec change.
3. **Edit-mode UX for .canvas**: edit JSON source (= current proposal) vs WYSIWYG drag (= much larger scope, ~600 LOC). WYSIWYG = future ticket.
4. **Cross-file linking**: `.canvas` file with `file` node referencing `/Chapters/c1.md` → click opens chapter (= current proposal = existing `WenshuEditorServicesFactory.openChapter`). Or open in new tab (= HIG standard for cross-document links).

## Acceptance

- `.canvas` files render as infinite-canvas node-edge graph in preview mode
- `.canvas` files render as JSON source in edit mode (= `Cmd+E` toggle)
- `.base` files render as table / card / grid view (= 3-mode switcher)
- `.base` files render as YAML source in edit mode (= `Cmd+E` toggle)
- Both formats coexist with existing MD chapter rendering
- No new 3rd-party dependency IF boss approves hand-rolled YAML parser
- OR `Yams` 5.x pinned IF boss approves new dependency (= passes §11.1)
