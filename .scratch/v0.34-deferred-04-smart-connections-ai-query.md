## Goal

Embed the AI query panel inside the editor zone (= right-side inspector pane, like Apple Notes' collaboration panel). User can ask natural-language questions about the current chapter (= "show every place Marcus mentions the temple") and get grounded citations (= chapter + line range) back from the LLM connector layer.

## User-Facing UX

- **Trigger**: Cmd+J (= standard macOS shortcut, no clash with Cmd+I italic / Cmd+B bold) OR click `Sparkles` Lucide icon in editor top bar.
- **Panel position**: right-side inspector pane (= Apple HIG standard inspector slot, like Finder Inspector or Notes Collaborators). Width = 320 PT (= HIG standard inspector width). Collapses / expands via sidebar toggle.
- **Input**: text field at top (= placeholder: "Ask about this chapter…"). Multi-line expand on Shift+Enter (= HIG standard).
- **Send**: Enter (= send query). Loading state = `ProgressView()` (= HIG standard spinner).
- **Response**: rendered below input. Each AI response = markdown render via existing `swift-markdown` (= already pinned). Citations = inline superscript numbers (= Apple HIG footnote convention) that on hover show tooltip with chapter path + line range.
- **Memory**: query history per book persists via `@AppStorage("editor.smartQuery.history.<book-uuid>")` (= book-scoped). Cmd+Up / Cmd+Down navigate history (= HIG standard for input history).
- **Empty state**: when user opens panel without ever asking, show 3 example queries (= "Who is the protagonist?" / "Summarize chapter 3" / "Find foreshadowing about the sword"). Click example = sends it.
- **Provider selection**: top-of-panel dropdown (= Apple HIG `.picker` style) showing the 7 v1 connector profiles. Defaults to last-used profile (= persisted in `@AppStorage`).

## Apple HIG Justification

- **Rule 7 (Buttons / controls)**: send button = `Button(action:)` with `.buttonStyle(.borderedProminent)`. Apple system style. No custom-drawn send icon (= Lucide `send` only).
- **Rule 9 (Menu / shortcuts)**: Cmd+J = standard macOS shortcut for "jump to" (= HIG reserves J-prefix for jump-style commands). Cmd+Up / Cmd+Down = HIG input history navigation.
- **Rule 10 (Tab / navigation)**: inspector pane lives inside existing 6-zone layout (= new zone, but uses HIG inspector slot). No modal, no new window.
- **Rule 11 (State persistence)**: query history, last-used provider, panel-open state all via `@AppStorage`. Standard storage.
- **Rule 14 (Charts / graphs)**: response text rendered as Markdown via existing `swift-markdown` (= already pinned). No custom render.
- **Rule 17 (AI / generated content)**: AI responses render with `Sparkles` Lucide icon prefix (= Apple HIG "AI-generated" indicator convention, macOS 27 standard). Citations shown inline (= AI grounding = Apple HIG standard).

## Open Questions (for Boss)

1. **Inspector vs popover**: current proposal = inspector pane (= always-visible right slot). Alternative = popover from top-bar icon (= Apple HIG standard for transient tools like Spotlight). Inspector = better for repeated queries; popover = better for "occasional question".
2. **Provider default**: empty (= user must pick) vs remember-last (= current proposal) vs auto-pick cheapest? Boss §11 ratifies = "no default recommendation" = empty or remember-last only.
3. **Trivial gate scope**: existing `SmartQueryTrivialGate` skips "what's the chapter count" style queries (= no LLM call). Should gate extend to skip ALL queries that can be answered from book metadata (= chapter count, word count, character list)? Proposal = yes (= pure metadata answers = free).
4. **Multi-chapter scope**: query current chapter only (= current proposal) OR query whole book (= "who is the protagonist?" needs cross-chapter)? Cross-chapter = larger context window = slower response.
5. **AI indicator badge**: macOS 27 HIG standard requires AI-generated content to show a `Sparkles` icon prefix. Apply to ENTIRE response block (= current proposal) OR inline at first sentence only? Proposal = entire block.
