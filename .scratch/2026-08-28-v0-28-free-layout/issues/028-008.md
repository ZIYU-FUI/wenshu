# 028-008 — ZoneEditor SwiftUI self-implement (FancyZones port, no third-party)

**Type:** implement (1 commit)
**Blocked by:** 028-003, 028-007

## What to build

End-to-end: clicking "+ 新建网格布局" in LayoutPicker opens a full-screen grid editor. User sees a numbered translucent zone grid; click to split (SHIFT = flip orientation); drag to rubber-band select; selected zones become a Merge button target; shared edges are draggable resizers. 4 templates (Columns / Rows / Grid / Priority) + a zone-count stepper. Save converts the grid to a guillotine tree and registers it as a user preset; non-guillotine (pinwheel) arrangements disable Save.

**Zero third-party view-framework dependencies** (ADR-0008). All grid model + interactions self-implemented in SwiftUI.
