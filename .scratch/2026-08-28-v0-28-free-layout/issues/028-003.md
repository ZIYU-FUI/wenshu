## What to build

End-to-end: wenshu persists a true recursive split tree (not a flat pane array) per the hermes `LayoutNode` model. The `WorkspaceState` schema bumps from v1 → v2 with a Swift-native port of `/Volumes/ANAN/.hermes/hermes-agent/apps/desktop/src/components/pane-shell/tree/model.ts:163-417` (normalize / removePane / insertAtGroup / movePane / mergeZonesWithPane). UserDefaults JSON round-trip preserves correctness across launches. **Zero third-party dependencies** (ADR-0008).

## Reference source

`/Volumes/ANAN/.hermes/hermes-agent/apps/desktop/src/components/pane-shell/tree/model.ts` = 650-line TypeScript module. The Swift port is line-by-line translatable, preserving:
- `SplitNode { orientation: 'row' | 'column', children: LayoutNode[], weights: number[] }`
- `GroupNode { panes: string[], active: string, minimized?: boolean, tabStrip?: 'always' | 'never' }`
- Pure functions returning new trees (immutable updates)

## Acceptance criteria

- [ ] `WorkspaceState` schema bumped to v2; `SplitNode` added (= orientation + ordered children + parallel weights)
- [ ] `PaneNode` kept as the leaf (= tabs + frame), unchanged public API
- [ ] Pure functions ported (= 1:1 from hermes `model.ts`):
  - `normalize()` — canonical form (no empty groups, no single-child or same-orientation nested splits)
  - `removePane(node, paneId)` — pure removal with active-tab reassignment
  - `insertAtGroup(node, targetGroupId, paneId, pos, before?, activate?, edgeWeights?)` — center joins as tab; edges split group
  - `movePane(root, paneId, target)` — move = remove + insert, no-op guards for shape
  - `movePanes(root, paneIds, target, activeId)` — multi-tab drag with strip-order preservation
  - `mergeZonesWithPane(root, groupIds, paneId)` — FancyZones span merge
  - `setSplitWeights(node, splitId, weights)` — drag-resize weight update
  - `setActivePane(node, groupId, paneId)` — tab strip selection
  - `setGroupMinimized` / `setGroupTabStrip` / `reorderPanesInGroup` — supporting ops
- [ ] `WorkspaceStore.load()` migrates v1 → v2 (= hermes "retire v1 wholesale" pattern: drop v1 keys on detection, start fresh)
- [ ] `WorkspaceStore.save()` persists v2 tree as JSON
- [ ] Round-trip JSON encode → decode → equal test passes for v2 (= covers tree shape + weights + tabStrip + minimized)
- [ ] Unit tests for all 6 primary pure functions (= mirror hermes's test suite)
- [ ] No new build warnings
- [ ] **No new third-party entries in `Package.swift`** (= ADR-0008)
