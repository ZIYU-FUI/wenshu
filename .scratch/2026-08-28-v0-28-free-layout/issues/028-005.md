# 028-005 — 4 builtin layout presets registration

**Type:** implement (1 commit)
**Blocked by:** 028-003, 028-004

## What to build

End-to-end: wenshu ships **4 builtin layout presets** (Default / Focus / Terminal deck / Quad) registered into `WorkspaceStore.presets` at first launch. Each preset is a `LayoutPreset` (Codable struct from v0.27) holding a `WorkspaceState` v2 split tree. User can switch between them via the picker (built in 028-007); this ticket ships the data + the runtime switch logic.

## Built-in shapes (literal, ported from hermes `controller.tsx:392-432`)

### builtinDefault (the existing v0.27 6-zone layout)

```
split(row, [
  group([.projectSidebar]),
  group([.projectPreview]),
  group([.editor]),
  group([.specializedTools])
], [1, 1, 3.4, 1.25])
split(row, [
  group([.aiChat]),
  group([.aiDynamic])
], [1, 1])
]
```

(= upper 4 horizontal + lower 2 horizontal; same as v0.27 `makeBuiltinWorkspace`)

### builtinFocus (2 panes)

```
split(row, [
  group([.projectSidebar]),
  group([.editor, .projectPreview, .specializedTools, .aiChat, .aiDynamic])  // all 5 as tabs in editor
], [1, 4.6])
```

### builtinTerminalDeck (4 panes, top 3 + bottom 1)

```
split(column, [
  split(row, [
    group([.projectSidebar]),
    group([.editor]),
    group([.projectPreview, .specializedTools])
  ], [1, 3.2, 1.2]),
  group([.aiChat])
], [3, 1])
```

### builtinQuad (2x2 grid)

```
split(column, [
  split(row, [
    group([.projectSidebar, .projectPreview]),
    group([.editor])
  ], [1, 3]),
  split(row, [
    group([.aiChat]),
    group([.aiDynamic])
  ], [1.4, 1])
], [3, 1])
```

## Acceptance criteria

- [ ] `WorkspaceStore` exposes 4 builtin presets on first launch (when UserDefaults `wenshu.workspace.presets` is empty)
- [ ] Each preset has `isBuiltIn: true` (= `deletePreset` ignores built-ins, hermes pattern)
- [ ] Each preset has a stable UUID per app install (= hermes pattern: 4 builtins + N user-saved)
- [ ] `WorkspaceStore.loadPreset(_:)` swaps the current workspace to any of the 4 builtins
- [ ] `currentPresetID` updates to the loaded preset's ID
- [ ] Switching persists across app launches (UserDefaults round-trip)
- [ ] Names: "默认" / "Focus" / "Terminal deck" / "Quad" (= hermes vocabulary; spec.md i18n table)
- [ ] No new build warnings
