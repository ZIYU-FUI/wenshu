# 028-007 — LayoutPicker + TreeEditBar floating palette

**Type:** implement (1 commit, but possibly 2 if atomic coupling forces split)
**Blocked by:** 028-005, 028-006

## What to build

End-to-end: when edit mode is on, a floating **TreeEditBar** (26rem wide, centered, draggable header) appears with the **LayoutPicker** inside. LayoutPicker shows 4 builtin presets as thumbnail cards in a 4-column grid, a "+ 新建网格布局" dashed button below, and a "将当前排列保存为模板" reveal-to-input button at the bottom. Header has "重置" (ghost) + "完成" (outline) buttons. Clicking any preset card applies it (= `WorkspaceStore.loadPreset(_:)`); active preset has accent border.
