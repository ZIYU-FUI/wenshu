# 028-002 — LayoutPreset.builtinDefault shape

**Type:** grilling (boss)
**Blocks:** 028-003..028-010

## Question

`LayoutPreset.builtinDefault` (= the layout wenshu opens with by default)
should adopt one of three paradigms. Boss 8/27 OOB: "用新框架推荐的模式，不强制追求和现有的一至" (= use the new framework's recommended mode, don't force 1:1 with v0.26).

## Candidates

| # | Paradigm | Panes | Splitters | Module coverage |
|---|---|---|---|---|
| I | Xcode / IntelliJ | 5 (shelf + editor + inspector upper; chat + dynamic lower) | 5 (= 4 horizontal + 1 horizontal) | 1+2+4+5 visible; 3+6 deferred |
| II | FCP Browser | 3 (shelf + editor + inspector with chat/dynamic as tabs) | 2 | 1+2+4+5 in 3 panes; 3+6 deferred |
| III | Hermes / IDE hybrid | 5 upper + 2 lower | 4 | 1+2+4+5; 3+6 deferred |

Full diagrams in `module-inventory.md` (search for "Candidate I/II/III").

## Recommendation

**II** — FCP Browser paradigm. Reasoning:

- **Simplest split tree**: 2 splitters (= least drag overhead; matches the
  v0.27 boss 8/27 grill D1 "用户按自己习惯自由定制" — simplest default
  means most room to grow).
- **Chat + Dynamic as inspector tabs** = the same pattern as Hermes
  per v0.23 spec; reusing that surface area saves work.
- **Inspector right panel** is where Apple's macOS standard puts
  context (= cross-refs, book metadata, character info). This is the
  Apple HIG canonical pattern.
- **Modules 3 + 6 deferred** anyway; their eventual panes naturally
  dock to the inspector tabs.

I (Xcode) is the second choice — Xcode's debug band is more discoverable
than FCP's, but it adds 3 more splitters for no v0.28 benefit.

III (Hermes hybrid) is the worst of both worlds: it preserves the
v0.26 2-band shape (= chat as separate bottom band) but reorganizes the
upper band into 3 (= less surface area for the editor, which is the main
stage per v0.27 spec D5).

## Boss decision

**II** — FCP Browser paradigm. Boss ratified (2026-08-27 evening, this session).

**Boss addition**: "如果是用现代码升级，那要保留现在的基础" = LayoutShellView (the v0.26 6-zone) stays as the legacy fallback. WorkspaceView builtinDefault = II (FCP 3-pane). Both shells coexist; user toggles via Window menu (per 028-001 = b).
