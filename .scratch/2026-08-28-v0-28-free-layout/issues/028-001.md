# 028-001 — Layout opt-in default shape

**Type:** grilling (boss)
**Blocks:** 028-002..028-010 (all downstream tickets wait for this)

## Question

When the user opens wenshu, what is the default rendering?

- (a) Legacy `LayoutShellView` ON by default (= the 6-zone fixed HStack+VStack from v0.26); WorkspaceView is opt-in via Window menu toggle.
- (b) WorkspaceView ON by default; user can switch to legacy via Window menu.
- (c) Remember last (= UserDefaults `wenshu.workspace.lastUsedPresetID`; honors returning users).

## Context (boss 8/27)

> "我们现在没有用户，我们还在开发阶段."

Boss clarification: there are **no external users yet**; wenshu is still
in development. The "preserve existing user experience" rationale for (a)
does not apply. (b) becomes the recommended default. (c) is also
premature (= no returning-user history to honor; only the boss as the
sole user).

## Recommendation

**(b)** — WorkspaceView ON by default; user can switch to legacy via
Window menu if they need to. The development phase IS the upgrade
phase; no regression risk to mitigate (no users to regress).

## Boss decision

**b** — WorkspaceView ON by default; user can switch to legacy via
Window menu if they need to. The development phase IS the upgrade
phase; no regression risk to mitigate (no users to regress).

**Boss ratification (2026-08-27 evening, this session)**: confirmed b + added
"如果是用现代码升级，那要保留现在的基础" — LayoutShellView (v0.26 fixed
6-zone) stays as the opt-in fallback for users who want it.
