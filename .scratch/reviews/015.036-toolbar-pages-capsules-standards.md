### S5 — The in-code comment at file L1057-1060 says `居右 in .automatic placement (= left of 导出 in .primaryAction)` — but `.automatic` does not literally mean "right"; it means "system-default placement", which on macOS is typically center-trailing

The phrase `居右` is a Chinese shorthand for "right-aligned" (= Boss 21st OOB's intent). However, `ToolbarItemPlacement.automatic` does not literally mean "right" — it means "let the system decide, using default heuristics". On macOS, `.automatic` typically places items in the center-trailing region of the toolbar, but the exact position is system-dependent and can change between macOS versions.

The accurate description is: `.automatic` produces a placement slot that is **distinct from `.navigation` (left) and `.primaryAction` (rightmost)**, and because the 4 toggles are in `.automatic` while the export is in `.primaryAction`, the macOS toolbar slots them in **left-center / rightmost** positions respectively.
