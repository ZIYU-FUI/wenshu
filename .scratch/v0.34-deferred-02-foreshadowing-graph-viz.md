## Origin

Backend exists at `Sources/WenshuApp/Core/Agent/Specialized/ForeshadowingTrackerTools.swift` and view stub at `Sources/WenshuApp/Views/Tools/ForeshadowingView.swift`. Visualization layer (graph render) is missing.

## Goal

Render the foreshadowing tracker (= per-book plot threads with setup / payoff timestamps) as an interactive node-edge graph inside the editor zone's foreshadowing sidebar pane (= the existing 6-zone layout already has a slot for this at `PaneTabBar.foreshadowing`).

## User-Facing UX

- **Graph view (= new)**: nodes = foreshadowing entries (one per plot thread); edges = setup→payoff links. Node size = number of chapters touching the thread; node color = payoff-status (green = resolved, amber = planted, gray = abandoned).
- **Layout**: force-directed (= d3-style, but SwiftUI-native via `Canvas` API). Pan via two-finger drag, zoom via pinch / scroll. Apple HIG standard gesture set.
- **Click node**: opens detail popover (= Lucide `book-open` icon, title + chapters touched + status badge). Edits stay in popover; no modal.
- **Filter bar (= top of pane)**: status filter (3 checkboxes: planted / resolved / abandoned), chapter-range slider. Apple HIG standard `.picker` style.
- **Empty state**: when book has no foreshadowing entries (= common for new books), show centered `Sparkles` Lucide icon + "Plot threads you plant here will link to their payoff" + "Plant first thread" button (= opens existing `ForeshadowingEntryEditor`).
- **Tab integration**: new tab in the existing 6-zone sidebar pane tab bar (= `PaneTabBar.foreshadowing` slot already exists). Toggle = eye icon (= Apple HIG standard visibility toggle).

## Apple HIG Justification

- **Rule 6 (Layout / spacing)**: filter bar uses `DesignTokens.paneTabHotArea = 28 PT` (= no magic numbers). Graph node size min = 16 PT (= HIG minimum hit target), max = 48 PT.
- **Rule 7 (Buttons / controls)**: filter checkboxes use `Toggle(isOn:)` with `.toggleStyle(.checkbox)`. Apple system style.
- **Rule 10 (Tab / navigation)**: new tab lives inside existing `PaneTabBar` (= no new top-level nav). Click node = detail popover, NOT new tab (= respects user's current focus).
- **Rule 14 (Charts / graphs)**: force-directed layout runs on `@MainActor` in `TimelineView(.animation)` (= 60 FPS target, paused when window unfocused). Apple HIG Chart standard.
- **Rule 15 (Canvas / drawing)**: graph drawn via SwiftUI `Canvas` (= GPU-accelerated). No `NSView` override, no `CALayer` manipulation.
