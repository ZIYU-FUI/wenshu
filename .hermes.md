## The 10 hard rules (= pre-commit sweep blocks any violation)

### 1. Icon glyphs

Use `SFIcon(name, style: .X, color: .Y)` for every icon glyph in view
code. Naked `Image(systemName:)` is banned outside the 4 documented
exceptions (= `Label`'s icon slot / `.resizable` chain at ≥38 PT /
comment-only references / `Label(_, systemImage:)` site).

Central factory: `Sources/WenshuApp/UI/IconStyles.swift` (= 11 IconStyle
cases + 10 IconColor cases + SFIcon View struct).

### 2. Spacing

Use `DesignTokens.spacing*` for every spacing literal. Naked numeric
spacing is banned outside `Stack(spacing: 0)` (= canonical no-spacing
inline) + `Spacer(minLength: 0)` (= canonical no-spacing spacer).

Token selection: spacingHairline(1) / spacingCaption(2) / spacingIconic(4)
/ spacingTight(6) / spacingStandard(8) / spacingModerate(12) /
spacingLoose(16) / spacingSection(20) / spacingHero(28) / spacingRelaxed(10).

### 3. Corner radius

Use `DesignTokens.surfaceCornerRadius*` for every corner radius.
Naked numeric corner radius is banned. The deprecated `.cornerRadius(N)`
API is also banned (= migrate to `.clipShape(RoundedRectangle(cornerRadius:
DesignTokens.X))`).

Token selection: surfaceCornerRadiusSmallButton(5) / SmallChip(7) /
Window(10) / Card(11) / HeroCard(12) / ProgressCard(6).

### 4. Shadow

Use `DesignTokens.surfaceShadow*` for shadow radius + y-offset.

Token selection: surfaceShadowRadiusWindow(12) / RadiusButton(8) /
OffsetWindow(4) / OffsetButton(2).

### 5. Font styles

Use SwiftUI built-in text-style shorthand (= `.title / .title2 / .title3
/ .headline / .body / .callout / .subheadline / .footnote / .caption /
.caption2`) + optional `.monospaced()` / `.monospacedDigit()` / `.weight()`.

Naked `.font(.system(size: N))` is banned.

### 6. Body text color

Use SwiftUI hierarchical shape-style (= `.secondary / .primary /
.tertiary / .quaternary / .quinary / .windowBackground / .tint`) for body
text foreground/background.

Exception (= `Color.X.opacity(N)` is allowed): `AnyShapeStyle(Color(nsColor:
.windowBackgroundColor).opacity(N))` / severity semantic (.red / .orange
/ .green) badge bg / `DesignTokens.accentTintOpacitySubtle / Hero`.

### 7. View size limits

Use `DesignTokens.xxxMax*` for `.frame(maxWidth: N)` / `.frame(maxHeight: N)`
/ `.frame(minHeight: N, maxHeight: N)`. Naked numeric view-size limit
is banned outside `window minSize / maxSize / sheet size ideal`.

Token selection: chatBubbleMaxWidth(360) / metadataPanelMaxWidth(320) /
attachmentPreviewMaxSize(240) / planListMaxWidth(420) /
onboardingWelcomeMaxWidth(480) / panelInlineMaxHeight(100) /
textEditorCompactMaxHeight(120) / textEditorSmallMaxHeight(140) /
textEditorMediumMaxHeight(160) / panelMediumMaxHeight(180) /
panelLargeMaxHeight(220) / commandPaletteMaxHeight(320) /
kanbanBoardMaxHeight(360) / textEditorSmallMinHeight(80) /
textEditorMediumMinHeight(100) / chatInputBarHeight(80) /
controlHeightLarge(36).

### 8. ≥38 PT icon sizes

Use `IconStyle.hero / .cover / .avatar / .emptyStateHero / .toolbarButton /
.surface` (= thin weight split) for every icon glyph at ≥38 PT. Naked
`.imageScale(.large)` is banned outside `ContentUnavailableView` (= HIG
default 38 PT).

Map: `.toolbar / .paneTab / .inlineSmall / .small / .nav / .hitArea`
(<38 PT, regular weight) vs `.hero / .cover / .avatar / .emptyStateHero /
.toolbarButton / .surface` (≥38 PT, thin weight).

### 9. Icon color

Use `IconColor` semantic enum (= `.tint / .secondary / .tertiary /
.quaternary / .primary / .red / .green / .orange / .blue / .accent`)
for every `SFIcon(..., color:)` call. Bare `Color.X` in icon color
context is ambiguous (= `SFIcon` has 2 overloads; = disambiguate via
`IconColor.X` prefix).

### 10. Apple HIG first

When adding a new number (= spacing / size / opacity / duration / etc.),
check Apple HIG first. If Apple HIG defines a canonical value (= e.g.
`ControlSize`, `HierarchicalShapeStyle`, `Padding`, `Spacing`), use the
canonical value. Only wenshu-invent a number when no Apple HIG mapping
exists.

Boss 2026-10-01 verbatim: "只有过大尺寸需要细体. 正常苹果有定义的尺寸
有默认. 非标的, 苹果没有的尺寸, 我们尽量改成苹果常用的. 不要自己定义
一些奇奇怪的尺寸."

## Pre-commit auto-check (= 9 grep commands, embedded below)

Run this sweep BEFORE `git commit`. Any hit = commit blocked.

```bash
# Rule 1 — naked Image(systemName:) outside exceptions
grep -rnE 'Image\(systemName: "[^"]+"\)' Sources/WenshuApp/ \
    | grep -v IconStyles.swift | grep -v ComponentIndex.md \
    | grep -v "// " | grep -v "Label { " | grep -v "\.resizable"

# Rule 2 — naked Stack(spacing: N) where N > 0
grep -rnE '(VStack|HStack|ZStack|Group|LazyVStack)\(.*spacing:\s*[1-9]' \
    Sources/WenshuApp/ | grep -v DesignTokens.swift | grep -v "// "

# Rule 3 — naked cornerRadius numeric
grep -rnE 'cornerRadius: [0-9]+(\.[0-9]+)?' Sources/WenshuApp/ \
    | grep -v DesignTokens.swift | grep -v "// "

# Rule 4 — naked shadow radius / offset
grep -rnE '\.shadow\([^)]+radius: [0-9]+' Sources/WenshuApp/ \
    | grep -v DesignTokens.swift
grep -rnE '\.shadow\([^)]+y: [0-9]+(\.[0-9]+)?' Sources/WenshuApp/ \
    | grep -v DesignTokens.swift

# Rule 5 — .font(.system(size: N)) long form
grep -rnE '\.font\(\.system\(size:' Sources/WenshuApp/ | grep -v "// "

# Rule 6 — raw Color.X.opacity(N) for body text (= outside exception)
grep -rnE 'Color\.\w+\.opacity\([0-9]\.[0-9]+\)' Sources/WenshuApp/ \
    | grep -v "// "

# Rule 7 — naked .frame(maxWidth: N) / .frame(maxHeight: N)
grep -rnE '\.frame\(maxWidth: [0-9]+' Sources/WenshuApp/ \
    | grep -v DesignTokens.swift
grep -rnE '\.frame\(maxHeight: [0-9]+' Sources/WenshuApp/ \
    | grep -v DesignTokens.swift

# Rule 8 — naked .imageScale at large size
grep -rnE '\.imageScale\(\.(large|medium)\)' Sources/WenshuApp/ \
    | grep -v IconStyles.swift | grep -v "// "

# Rule 9 — bare Color.X in SFIcon color context
grep -rnE 'SFIcon\([^)]+color: \.\w+' Sources/WenshuApp/ \
    | grep -v IconStyles.swift
```

If any check returns a hit, refactor before commit (= use the canonical
`SFIcon` / `DesignTokens` / `IconColor` / SwiftUI built-in). If no
canonical mapping exists (= wenshu-invented value), add the new token
to `DesignTokens` with the 4-field Apple-HIG doc-comment template.

## Apple HIG first (general rule)

When unsure about ANY UI decision (= icon size / spacing / color / font
weight / opacity / shadow radius / hit area / control size), measure
Apple's first-party apps (= Pages / Numbers / Xcode / Mail / Messages
/ System Settings / Safari / Finder). Wenshu has no authority to invent
a different value. If Apple HIG defines a canonical value, use it.
