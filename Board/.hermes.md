## What every board-client turn MUST check

1. **Apple HIG first** (`wenshu-apple-api-first` chain). Never invent a number
   or visual layer Apple already ships. Freeform is Apple's own board app and
   the reference for the vocabulary; check the SDK, not memory. The quotes
   are in `docs/freeform-card-model.md` §3.
2. **The card model is the client's.** `Board/Sources/WenshuBoardKit/` owns the
   element envelope, the placement regimes and the order key. It does not
   import the desktop app's sources: the desktop app is an executable target
   and is not consumable.
3. **The data layer is shared, read-only from here.** `Sources/WenshuData` is
   consumed as a local path package. The client does not write the library
   the desktop app has open (= one library, one writer).
4. **English-only** in code, comments, commits and all `.md` except `OOB.md`.
   The dev-process output is in Chinese; the committed artifacts stay English.
5. **One ticket = one commit** + atomic verification + a 4-section spec
   (= per AGENTS.md §8). A change under `Board/**` runs in its own git
   worktree, the way every other code change in this repository does.
